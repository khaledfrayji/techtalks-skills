# Security

This package installs readable workflow instructions. It does not execute agent tasks, access model APIs, collect credentials or grant permissions. Your agent runs with its existing permissions.

Inspect installed instructions before using them with sensitive repositories. Do not put secrets or customer data in project context documents. Repository content and external text should be treated as untrusted evidence.

For a suspected vulnerability, use this repository's private security advisory reporting if enabled. If unavailable, contact the maintainer through an established private channel; do not disclose exploit details or credentials in a public issue. This repository does not promise a staffed response deadline.

Supported fixes target the latest release. Include package and Node versions, platform, a minimal reproducer and observed impact using synthetic data.
